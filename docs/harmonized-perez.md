# Canonical Harmonized Perez Baseline

The canonical production baseline is generated by `codes/run_harmonization.py` and published in `outputs/HARMONIZED_PEREZ_2003CLP_v1/`. It promotes the previously validated Perez candidate path into the public production interface while leaving the frozen Hofman accounting reference untouched.

## Control concept

The canonical control total is Perez fixed capital formation excluding inventories:

- include machinery
- include construction
- exclude inventory variation

In this repository, "ex inventories" means excluding inventories, not ex post.

## Production logic

1. Read Perez aggregate fixed-capital flows from `data/raw/PerezEyzaguirre_DemandaAgregada.xlsx`.
2. Read `lambda_choice` from `outputs/DIAGNOSTIC_LEVEL_NORMALIZATION_LAMBDA_v1/lambda_estimates.yaml`.
3. Scale Perez aggregate ex-inventory investment by `lambda_choice`.
4. Split the scaled total into `ME`, `NRC`, and `RC` using normalized Hofman investment shares from `data/raw/Hofman2000_GrossInvestment.xlsx`.
5. Reuse frozen Hofman survival parameters from `outputs/survival_fit_hofman_1980.csv`.
6. Reuse frozen-baseline gap ratios recovered from `outputs/harmonized_series_1980CLP_1900_1994.csv`.
7. Emit full panel outputs, audit summaries, regression checks, and provenance metadata.

## Constraints established by code

- Primary price space is fixed at 2003 CLP.
- Lambda is a level bridge, not a unit conversion.
- Inventories are excluded from accumulation entirely.
- Production fails if overlap admissibility fails.
- Production fails if full-period admissibility fails.
- Production fails if the promoted series diverges beyond tolerance from the existing extension candidate path.

## Canonical outputs

The committed public output bundle is `outputs/HARMONIZED_PEREZ_2003CLP_v1/`:

- `harmonized_series_2003CLP_1900_1994.csv`
- `harmonized_series_2003CLP_1900_1994.xlsx`
- `assumptions.yaml`
- `overlap_audit_summary.txt`
- `audit_summary_full_1900_1994.txt`
- `violation_log.csv`
- `summary.md`

`assumptions.yaml` is the machine-readable contract. It records the canonical command, git commit, repo clean/dirty status, Python version, and SHA256 hashes of required inputs.

The Excel file is a direct single-sheet serialization of the long canonical panel, using the worksheet name `harmonized_panel`. It is not a pivoted or editorialized reporting table.

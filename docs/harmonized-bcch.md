# Additive BCCh Harmonized Bundle

The additive BCCh bundle is generated by `codes/run_harmonization_bcch.py` and published in `outputs/HARMONIZED_BCCH_2003CLP_v1/`. It does not replace the canonical Perez `1900-1994` baseline. Instead, it preserves that validated history exactly and extends the stock panel forward to `2024`.

## Stock logic

The bundle keeps the current harmonized panel unchanged through `1994`, then appends BCCh-informed post-1994 dynamics.

Production logic:

1. Read the canonical `1900-1994` panel from `outputs/HARMONIZED_PEREZ_2003CLP_v1/harmonized_series_2003CLP_1900_1994.csv`.
2. Read BCCh real net stocks from sheet `1` of `data/raw/BCCH_1985_2024.xlsx`.
3. Read BCCh real depreciation from sheet `2` of `data/raw/BCCH_1985_2024.xlsx`.
4. Crosswalk BCCh assets into `RC`, `NRC`, and `ME`.
5. Recompute `NR` and `Total` from components and use BCCh published totals only as extraction audits.
6. Compute asset-specific `1994` bridge factors from canonical `Kn_1994 / BCCh_Kn_1994`.
7. Apply the same bridge factor to each asset’s BCCh `Kn` and `D` path.
8. Set `Kn` for `1995-2024` equal to the scaled BCCh component series.
9. Infer post-1994 real investment with `I_t = DeltaKn_t + D_t`.
10. Reuse frozen Hofman survival parameters to reconstruct `Kg` and `R` for the extended history.

## Pk logic

The companion `Pk` surface is published separately from the stock panel:

- primary source `1960-2024`: BCCh ratio deflator `FBKF_nom / FBKF_real` from `data/raw/BCCH_ref2018_Pk.xlsx`, rebased to `2003=100`
- backcast `1940-1959`: ClioLab ratio-deflator growth from `data/raw/ClioLab_GFKF_Freal_nominal_Pk.xlsx`, chained to the BCCh ratio level at `1960`

The public `Pk` diagnostics are ratio-only. `pk_splice_diagnostics.csv` records the rebased BCCh ratio build, the chained Clio backcast, year-quality flags, and the single source switch at `1960`.

## Constraints established by code

- Primary stock price space remains fixed at `2003 CLP`.
- Legacy `1900-1994` rows must remain exactly equal to the canonical Perez panel.
- BCCh starts the stock extension at `1995`.
- The repo does not publish nominal capital-stock series.
- `2023` and `2024` remain in the bundle with explicit provisional and preliminary flags in the diagnostics and `Pk` output.

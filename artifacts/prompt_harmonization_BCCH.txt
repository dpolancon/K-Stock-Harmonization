I've created a branch, to work the splicing of our data set with the NET capital stock of in the folder of the repo with data series from the Central Bank of Chile, extensions:  
- "data/rawBCCH_1985_2024.xlsx"  where you can identify the following variables in constant and real prices: 
     + "Edificación habitacional"  (RC) 
     + "Resto construcción" (NRC) 
     + "Maquinarias y equipos" (ME) 
     + "Total" (T) 
- Several points should be noted, the .xlsx file has several sheets with numbers "1", "2", up to "6": 
     + "1" contains the four variables as written above, you need to crosswalk to the notation of this project for capital stock and build the implicit variables such as total capital stock for the non residential sector (NR) and validate total capital stocks when necessary 
     + Real from Nominal capital stocks can be identified as "Precios constantes"  and "Precios corrientes" respectively. 
     + This distinction in the data set is "per sheet" in sheet. We'll be using sheet "1" and sheet "2" 
     + Sheet "1" has data on "Stock de capital neto por tipo de activo, 1985-2024 (1)(2)", i.e.  K net in our notation. 
     + Sheet "1" contains real capital stocks with the first data rwo for RC NRC ME T ranging cell span C10:F10 while B10:B49 with the first period year: 1985 running up to 2024 (note: years 2023 and 2024 have a (3) and (4) note signaling provisionary measures, and preliminary correspondingly. 
     + Likewise, sheet "1" also contains nominal  capital stocks with the first data rwo for RC NRC ME T ranging cell span H11:F11 while B11:B49 with the first period year: 1986 running up to 2024 (note: years 2023 and 2024 have a (3) and (4) note signaling provisionary measures, and preliminary correspondingly.
     + Hence, we can leverage on real capital stocks having data for 1985, but considering that this source has complete information for 1985-2024, considering warnings for 2023-2024 period. Otherwise, are oficial. 
     + Similarly, sheet "2" presents data for "Consumo de capital fijo por tipo de activo, 1985-2024 (1)(2)", i.e.  D_t in our notation. 
     + Thus, the data set presents implicit depreciation rates for net capital stocks, i.e. d_t in our notation. 
     + Note: all data is on "Miles de millones de pesos", i.e thousands million pesos.

# K-Stock-Harmonization: Reproduction Package for Chile Capital Stock Harmonization (1900–2024)

This repository serves as the official **Reproduction Package** for new measurements from harmonized sources on net and gross capital stocks, implicit depletion and depreciation rates, and capital deflators for Chile (1900–2024).

It adheres to the **AEA Data Editor Guidelines (American Economic Association)** and **FAIR Principles for Research Data/Software**.

---

## 1. Executive Summary & Definitive Source of Truth

The repository harmonizes capital stock data for Chile across three accounting/production surfaces:
1. **Frozen Accounting Reference**: Hofman baseline in constant 1980 CLP (`1900–1994`) generated by `codes/run_baseline_hofman_1980.py`.
2. **Canonical Harmonized Baseline**: Perez FBKF baseline in constant 2003 CLP (`1900–1994`) generated by `codes/run_harmonization.py`.
3. **Additive BCCh Extension Bundle (Definitive Surface)**: Extended panel in constant 2003 CLP (`1900–2024`) generated by `codes/run_harmonization_bcch.py`.

### Definitive Master Dataset Surface
The master dataset unifying all stock/flow measures, implicit rates, and capital deflators into a single flat file is located at:

```
outputs/HARMONIZED_BCCH_2003CLP_v1/harmonized_master_dataset_2003CLP_1900_2024.csv
outputs/HARMONIZED_BCCH_2003CLP_v1/harmonized_master_dataset_2003CLP_1900_2024.xlsx
```

- **Variables Included**: Investment ($I$), Real Gross Capital Stock ($K_g$), Real Net Capital Stock ($K_n$), Capacity Backlog / Discards ($B = K_g - K_n$), Gross Retirements / Depletion ($R$), Net Depreciation ($D$), Rate of Gross Disposals ($z = R / K_{g,t-1}$), Rate of Net Depreciation ($\delta = D / K_{n,t-1}$), and Capital Price Index ($P_k$, 2003=100, populated 1940–2024).
- **Asset Classes**: Machinery & Equipment (`ME`), Non-Residential Construction (`NRC`), Residential Construction (`RC`), Non-Residential Total (`NR = ME + NRC`), and Total Fixed Capital (`Total = ME + NRC + RC`).

## 2. Quick Start & Master Reproduction Command

To reproduce all accounting surfaces, audit logs, and master dataset files from raw data in a single command, run:

```bash
python run_all.py
```

### Computational Requirements
- **Operating System**: Cross-platform (Windows, macOS, Linux).
- **Software Dependencies**: Python 3.10+ (Dependencies specified in `requirements.txt` and `environment.yml`).
- **Execution Time**: ~5 to 10 seconds.
- **Memory Footprint**: < 200 MB.

## 4. Individual Step Reproduction Commands

If you prefer executing individual pipeline components:

### Step 1: Frozen Hofman Accounting Reference (1980 CLP)
```bash
python codes/run_baseline_hofman_1980.py
```
Output: `outputs/harmonized_series_1980CLP_1900_1994.csv`

### Step 2: Canonical Perez Harmonized Baseline (2003 CLP, 1900–1994)
```bash
python codes/run_harmonization.py
```
Output directory: `outputs/HARMONIZED_PEREZ_2003CLP_v1/`

### Step 3: Additive BCCh Extension Bundle & Master Dataset (2003 CLP, 1900–2024)
```bash
python codes/run_harmonization_bcch.py
```
Output directory: `outputs/HARMONIZED_BCCH_2003CLP_v1/`

## 5. Machine Provenance & Audit Guarantees

Both 2003 CLP publication bundles log machine-readable provenance in `assumptions.yaml`:
- Exact git commit hash and clean/dirty repository state.
- Python runtime environment version.
- Cryptographic SHA-256 hashes of all required raw inputs.
- Hard-anchor bridge factors and price splice diagnostic summaries.

All pipeline outputs enforce non-negativity of stocks, identity consistency ($\Delta K = I - D$ / $\Delta K_g = I - R$), and additivity of components ($NR = ME + NRC$, $Total = NR + RC$).
